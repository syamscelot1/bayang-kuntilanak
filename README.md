# Bayang Kuntilanak

Game horor 2.5D ala Little Nightmares — cerita orisinil Bahasa Indonesia. Dimas, anak kecil berjas hujan kuning, tersesat di hutan bambu tengah malam. Ia harus mengumpulkan 3 sesajen — bunga melati, kemenyan, dan lampion — lalu meletakkannya di punden tua, sambil menghindari Kuntilanak yang melayang di antara bambu.

## Main di Windows

1. Download `Bayang-Kuntilanak-windows.zip` dari [Releases](https://github.com/syamscelot1/bayang-kuntilanak/releases).
2. Extract zip-nya, lalu jalankan `Bayang-Kuntilanak.exe`.
3. Windows 10/11 64-bit.

## Main di browser (HP/PC)

1. Download `Bayang-Kuntilanak-web.zip` dari [Releases](https://github.com/syamscelot1/bayang-kuntilanak/releases).
2. Extract, buka `index.html` di browser (Chrome dianjurkan).
3. Di HP: putar ke landscape untuk bermain. Atau main langsung di [GitHub Pages](https://syamscelot1.github.io/bayang-kuntilanak/).

## Menu

- **New Game** — mulai dari awal (save lama ditanya dulu sebelum ditimpa)
- **Load Game** — lanjut dari checkpoint terakhir (autosave tiap lilin menyala dan tiap sesajen terambil)
- **Options** — volume musik, volume efek suara, kualitas grafik (Tinggi/Rendah)
- **Cara Main** — panduan lengkap

## Kontrol

- A/D atau panah kiri/kanan: gerak | W/S atau panah atas/bawah: maju/mundur dalam hutan | F: lentera | Shift: lari | E: ambil / sembunyi / pakai | Esc/P: pause
- Sentuh (HP): joystick kiri untuk gerak, tombol LENTERA / LARI / AMBIL di layar.

## Fitur

- Dunia 2.5D serba besar dibanding Dimas yang mungil, kabut tebal, kunang-kunang, cahaya bulan + lentera hangat
- Kuntilanak: melayang, cekikikan, patroli — melihat dan mendengar, mengejar kalau ketahuan
- 3 tempat sembunyi: lubang bambu besar, kolong gubuk tua, balik bambu tumbang — sembunyi untuk memutus kejar-kejaran
- Teka-teki dorong peti bambu ala Little Nightmares
- Lentera + baterai cadangan, checkpoint lilin, 3 nyawa
- Jumpscare saat tertangkap dan saat sesajen ke-3 ditaruh
- Kejar-kejaran final menuju gerbang desa
- Animasi jalan, lari, idle menoleh, jongkok sembunyi, lentera berayun
- Teks dan audio Bahasa Indonesia (audio synth, tanpa file eksternal)
